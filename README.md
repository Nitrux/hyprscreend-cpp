# Hyprscreend | ![License](https://img.shields.io/badge/License-BSD--3--Clause-blue)

# Introduction

Hyprscreend is a unified C++ daemon that manages Hyprland monitor modes, scaling, power-dependent refresh rates, and external display hotplugging.
